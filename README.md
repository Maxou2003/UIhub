# 🌐 UIHub – Create and Share UI Components
HubShare is a collaborative web platform that allows users to create, publish, and explore user interface (UI) elements. The goal is to promote the sharing of reusable UI components among designers and developers around the world.

## 🚀 Features

- ✏️ **UI Creation**: An intuitive editor for designing UI components.
- 📤 **Easy Sharing**: Publish your creations and make them accessible to the community.
- 🌍 **Discover**: Browse UI components created by others and reuse them in your own projects.
- ❤️ **Favorites**: Make sure you always have them around.

## 🔧 Tech Stack

- **Frontend**: React, React-router-dom 
- **Backend**: Node.js, Express  
- **Database**: MongoDB  
- **Authentication**: JWT, Bcrypt 


## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Maxou2003/UIhub.git
cd UIHUB

# Install server's dependencies
npm install --force

# Install client's dependencies
cd client
npm install --force
cd ..

# Start the development server
npm run dev
```

## 🔑 Environment Variables
Create a **.env** file in the root directory and add the following variables:
```bash
DATABASE_URL='your_database_url'
SECRET_TOKEN='your_secret_token'
```
